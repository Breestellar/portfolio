PROJECTS

Each project is presented around the problem it addresses, the approach I took, and what I actually built.

01

Web application

SmartTenant

Multi-user property & tenant management system

The problem

Landlords and tenants often manage rent records, lease terms, complaints and communication through disconnected tools or none at all, making it easy for information to get lost.

The approach

I built a role-based web application that gives landlords and tenants separate, permissioned views of the same data so each side only sees and edits what applies to them.

What I worked on

Role-based access control, automated PDF lease generation, an AJAX-driven messaging system between landlords and tenants, a lease termination workflow, and a complaint management module, all with a consistent interface across every page.

Flask MySQL Tailwind CSS AJAX xhtml2pdf

02

Navigation tool

TUM Room Locator

Campus navigation with live GPS guidance

The problem

Finding a specific room on a large unfamiliar campus wastes time for students and staff, especially during the first weeks of a semester.

The approach

I built a focused navigation tool for the Technical University of Mombasa that turns a room name into a walkable route with real-time position tracking instead of a static map.

What I worked on

Route calculation and rerouting with OSRM, GPS signal smoothing to keep the map stable, voice-guided directions and the interactive Leaflet.js map interface.

Flask MySQL Leaflet.js OSRM Geolocation API Web Speech API
